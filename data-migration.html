Context & Diagnosis

Maison Verte Services maintains boilers and heat pumps for ~480 homes and businesses around Bourg-en-Bresse and Lyon. For 12 years they've run on a desktop tool that can't schedule technicians or send contract renewals, so the office does both in Excel. Renewals get missed, and contracts lapse without anyone calling the customer.

The new field-service platform automates renewals, but only if the contract data it receives is right. That makes the migration the part of the project where the money is.

Deliverable 02

The Toolkit — Mapping Spec as Code

1
profile

Detects encoding and delimiter, and shows each column's value shapes: 99999 ×340 next to 9999 ×145 means lost leading zeros

2
suggest-mapping optional AI

Drafts source→target mapping with a confidence and a reason per line. Offline heuristics, or Claude with --ai (headers + 5 samples; --mask sends formats only). A draft for a human to approve, never auto-applied.

3
dry-run

Transform, validate, de-duplicate, reconcile. Every row gets exactly one outcome, and the run ends in GO / NO-GO with reasons

4
load

Refuses to run on NO-GO. Batched upserts keyed on legacy ID (re-runs don't duplicate), 429s retried with exponential backoff, then reconciled against the target

5
rollback

Every row remembers the run that wrote it; one command removes a whole run

One Outcome Per Row
OutcomeMeaning
acceptedLoaded (flagged if it carries a warning)
mergedDuplicate folded into a survivor; its contacts & contracts re-linked
skippedValid but out of scope by agreement (terminated contracts)
rejectedCan't be loaded; goes to the customer with a reason they can act on
# config/v3.yaml (the mapping spec, executable) annual_value: {source: "Montant annuel HT", transforms: [amount_fr], required: true} postcode: {source: "CP", transforms: [postcode_fr], required: true} dedupe: strong_key: siret # merge (D-02) review_keys: [name, postcode] # flag only
Built for the person who'll open it: exceptions files are UTF-8 with BOM and ; separators, so they open correctly in French Excel with a double-click, and every row says what to do next.

Deliverable 04

Incident — €90,295.61 Misread, Zero Errors

CRITICAL: would have under-stated active contract revenue by 12.9% in the new platform. 23 business contracts would have shown €1–€7 a year, and renewal emails would have quoted €2.40 instead of €2,400.

Root Cause
Legacy valueMeaningParser v2 read
1 250,50€1,250.501,250.50 ✅
189,90 €€189.90189.90 ✅
2.400€2,4002.40 ❌

The legacy tool prints whole-euro amounts ≥ €1,000 with a dot as the thousands separator. The parser treated every dot as a decimal point. 2.40 is a valid, positive number, so nothing failed.

Why Only the Control Total Caught It
  • Row counts: the 23 rows were loaded and counted correctly; they just held the wrong values
  • Validation: 2.40 passes every rule
  • Our own totals: we'd have summed the same wrong values and matched ourselves
  • The customer's report doesn't depend on any code I wrote
Reproduce → Fix → Verify
# tests/test_transforms.py: the bug, pinned forever def test_amount_naive_silently_reads_thousands_dot_as_decimal(): assert t.amount_naive("2.400") == 2.40 # migrate/transforms.py: the fix # a dot followed by exactly 3 digits, no comma = thousands _THOUSANDS_DOT = re.compile(r"^\d{1,3}(\.\d{3})+$")
$ python -m migrate dry-run --config config/v2.yaml NO-GO - contracts.annual_value: €90,295.61 unexplained vs. the legacy control total $ python -m migrate dry-run --config config/v3.yaml GO
Corrective Actions
  1. French-rules amount parser + a regression test for every format seen
  2. The profile had shown 9.999 ×25, but only as the 5th shape, and it displayed the top 3. It now shows every shape above 2% of rows.
  3. Control totals stay a hard go-live gate, not a warning
  4. Kickoff checklist: one control total per money or quantity field, same day as export

What This Project Demonstrates

Asking for proof that doesn't depend on me

The control total was requested at kickoff, before a single line of mapping existed. It's the check that caught the one bug nothing else would have.

Knowing what to repair and what to hand back

1000 → 01000 is certain, so it's repaired. 31/02/2023 isn't "probably the 28th", so it goes back to the customer with a reason.

Decisions with owners, not silent defaults

Seven decisions, each dated and agreed by a named person on the customer side.

Engineering for the operational reality

Idempotent loads, retry with backoff, run-level rollback, stale-row detection, and exceptions files built for French Excel.
